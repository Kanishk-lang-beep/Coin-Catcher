# Coin Catcher

A pixel-art catcher game made in Unity 6. Move the basket to catch falling coins and dodge the bombs.

## How to play
- Move with **A / D** or the **left / right arrow keys**, or hold the **left mouse button** to chase the cursor.
- Catch **coins** to score points.
- Missing a coin or catching a **bomb** costs a heart.
- Lose all 3 hearts and it's game over. Click or press **R** to restart.
- The game gets faster the longer you survive, and your best score is saved.

## Features
- Pixel-art sprites and a night-sky background
- Spinning coin animation
- Pixel particle bursts and screen shake
- Pixel-font HUD with score, best score and lives
- Chiptune music and sound effects

## Run it
1. Install Unity 6 (6000.6.7f1) from Unity Hub.
2. Clone this repo and open the folder in Unity Hub.
3. Open `Assets/Scenes/SampleScene` and press Play.

Requires the Input System package (included by default in Unity 6 projects).
